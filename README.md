# homebrew-moderado

Homebrew tap for [Moderado](https://github.com/marcuz-apl/moderado) (free-first AI coding agent).

```bash
brew tap marcuz-apl/moderado
brew install moderado
```

The `Formula/moderado.rb` file is generated from verified release checksums by
`npm run generate:manifests` in the main repo and pushed here by CI on each
release. Binaries are unsigned; macOS Gatekeeper may prompt on first run.
